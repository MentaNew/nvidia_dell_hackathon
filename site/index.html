Incident intelligence that keeps working when the network goes down.

When a disaster cuts connectivity, cloud AI disappears exactly when it is needed. RescueBase runs on one machine at the command post, a Dell Pro Max with GB10: drone imagery and crew radio become source-linked draft events on a shared timeline, analysed entirely locally. Nothing is confirmed until a person confirms it.

Try it

A working recreation of the command-post app, running in your browser on recorded inputs. Start with the three-step tour, then drop any file yourself. The app logic is real; only the model outputs are pre-recorded.

Things to try

  1. Drop an aerial photo: the vision model's draft events appear with the image as evidence.
  2. Drop report1.txt, then its copy: the copy is recorded as a duplicate, not a second source.
  3. Click Cut the external internet. The log keeps working.
  4. Confirm or reject an event. Every event starts as an AI candidate.
  5. Ask the log: “What has been reported in Sector 4?”
  6. Open SITREP for a report short enough for a constrained radio link.
  7. Drop bad.png: it retries, fails, and never blocks the queue.

The aerial photos are real public-domain FEMA photos (2007 and 2008), standing in for drone frames and labelled ARCHIVAL. The text inputs are the field reports from the project's test suite; the incident is simulated.

How it works

Files dropped into a local inbox are analysed on the GB10. Each result becomes a draft event linked to its evidence, with capture time kept separate from ingestion time.

Inbox
Drone frames, clips and radio audio land in a watched folder.
Local analysis
Qwen3-VL reads images; Whisper transcribes radio, all served by vLLM.
Draft events
Typed, source-linked, with model-stated confidence.
Shared timeline
Ask the log questions; get a short SITREP.
Human review
A person confirms or rejects every event.

No victim or casualty claims, no dispatch orders, no “safe” or “passable” judgements.

Visual observations and spoken reports stay separate; their agreement is not confirmation.

Locations come from EXIF or a sidecar file only, never from a model's guess.
